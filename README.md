# Vinheria Agnello - Check-Point 03

Página feita para o Check-Point 03, usando o tema da Vinheria Agnello. A ideia foi praticar Flexbox, pseudo-classes e transformações no CSS.

## O que foi usado

**Flexbox**
- Cabeçalho com o nome de um lado e o menu do outro
- Cards dos vinhos lado a lado (com `flex-wrap`)
- Seção de destaque e formulário centralizados com `flex-direction: column`

**Pseudo-classes**
- `:hover` nos links do menu, no botão e nos cards
- `:focus` nos campos do formulário

**Transformações**
- `scale` no botão
- `rotate` + `scale` nos cards
